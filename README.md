# 🔗 SoloLink

**SoloLink** is a multi-user link-in-bio web application where users can create a personalized public profile and share their important links from a single page.

## 🚀 Live Demo

**[Open SoloLink](https://sololink.pages.dev)**

## ✨ Features

- 🔐 User authentication
- 👤 Personalized profiles with name, bio and profile photo
- 🆔 Unique usernames with public profile URLs
- 🔗 Add, delete and reorder links
- 💾 Persistent user and profile data
- 🛡️ Users can edit only their own profiles
- 🌐 Public profiles accessible without login
- 📱 QR-code sharing for quickly opening a user's public profile
- 📱 Responsive interface

## 🛠️ Tech Stack

- **React** — Frontend
- **JavaScript** — Application logic
- **HTML & CSS** — Structure and styling
- **CRACO** — Build configuration
- **Database** — Persistent data storage
- **Cloudflare Pages** — Deployment

## 💻 Run Locally

```bash
git clone https://github.com/parthkumar10/sololink.git
cd sololink/frontend
npm install
npm start
```

The app will run at `http://localhost:3000`.
